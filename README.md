A fast, dependency-free reader for broken CSV files: a single-pass ES module (`solve.js`) that reproduces csv-reader 1.0.0's `{columns, rows, errors}` output exactly, plus a Node driver (`main.ts`) that reads `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
